# Sample notes

Notes written to trip every one of the editor's lenses, for testing the feedback types: an uncited rule of thumb (`evidence`, caught offline), a hedge-dense risk section (`clarity`, offline), overlapping customer groups (`mece`), a decision resting on one footfall number (`warrant`), an unstated staffing assumption (`assumption`), an objection nobody raises (`counter`), a `[no-ai]` section that must never be read, and a fenced SQL block whose `#` comments must not become headings.

| File | Language | Notes |
|------|----------|-------|
| `nordbrot.en.md` | English | The welcome tour's sample (`SampleNote.english` in `KlartMac/Sources/KlartKit/Models/SampleNote.swift` is the canonical, slightly revised copy the app creates) |
| `nordbrot.de.md` | German | Translation, same structure and flaws |
| `nordbrot.es.md` | Spanish | Translation (Panadería Aurora), same structure and flaws |

Import with **File ▸ Import Markdown Notes…**, or paste into a new note. Set Settings → Editor → *Language* to match, or leave it empty so the editor answers in the note's language.
